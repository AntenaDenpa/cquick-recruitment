## 三、三种通信方式对比

| 通信方式 | 模型 | 特点 | 足球机器人场景 |
|---|---|---|---|
| 话题 Topic | 发布/订阅，多对多 | 单向、持续流、不管对方在不在 | 视觉持续广播球位置；战术持续广播速度指令 |
| 服务 Service | 请求/响应，一对一 | 同步、有返回值、调一次答一次 | 「现在比分多少」「切到防守模式」 |
| 动作 Action | 目标/反馈/结果 | 长任务、报进度、可取消 | 「走到点 (1,1)」→ 过程报进度，可中途取消 |

**我实际用到的服务调用**：任务 2 开始前的 `ros2 service call /clear std_srvs/srv/Empty`。它必须等到服务端回应、调一次就结束，而且只是「清一次屏」这种一次性动作——这正是服务和话题的区别：话题是持续广播、没人听也照发；服务是点对点请求、必须有应答。

## 四、差速三公式

- `v = (vL + vR) / 2` → 两个轮子的速度取平均，就是车体往前的线速度。
- `ω = (vR − vL) / L` → 两轮速度差除以轮距，决定车体转多快；差速转向靠的就是左右轮速度不一样。
- `r = v / ω` → 线速度与角速度之比，就是车走的圆弧半径；ω 越小弯越大，ω=0 就是走直线。

## 五、踩过的坑 & 怎么解决的

1. `ros2 run ball_pos ball_pos_subscriber` 报 **No executable found** → 先执行 `ros2 pkg executables ball_pos` 看实际可执行名，发现 ament_cmake 用 `install(PROGRAMS)` 装的脚本**名字保留了 `.py` 后缀** → 改成 `ros2 run ball_pos ball_pos_subscriber.py` 就正常了。
2. 新终端里跑节点报找不到包 / `ModuleNotFoundError` → 原因是这个终端没 source → 每个新终端先 `source ~/ros2_ws/install/setup.bash` 再启动节点。
3. 一开始只开了导航节点、忘了开发布者 → `go_to_balls` 一直停在「等 3 个球」，乌龟不动 → 用 `ros2 topic info /ball_pos` 确认 Publisher 是不是 1，确认发布者在跑就好了。
